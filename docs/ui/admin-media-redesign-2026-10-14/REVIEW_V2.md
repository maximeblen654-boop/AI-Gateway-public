## 这次真正调整

- 中文从 Microsoft YaHei 换成本机已安装的 Noto Sans SC（思源黑体），标题 550–600 字重、正文 400；金额采用 Segoe UI Variable 的等宽数字。Chrome CSS.getPlatformFontsForNode 已确认真实字形来自 Noto Sans SC，而不是只改声明。
- 去掉外层大卡片、重复工作区导航文字和默认展开的成本工具。收起状态只呈现对象、步骤、价格表和下一步。
- 用白色工作区、浅灰输入、少量绿色选中状态及深色主按钮建立层级；保留浅深色分别定义的语义表面。
- 五步选中线和成本档位底板连续移动；抽屉 320ms 从右进入，手机从底部进入；按钮即时反馈；首次主体轻入场。减少动态效果时直接显示终态。
- 成本按售价档位打开，当前行与抽屉同时对应。采购参数可折叠；只强调关键差额。主表是唯一售价输入，抽屉只读跟随。
- 手机 390×844 抽屉为近全屏面板，固定标题与关闭入口、内部可滚动；背景 inert，关闭后返回原操作区域。

## 可直接体验

原本机预览地址为 http://127.0.0.1:4396/v2/index.html；GitHub 副本的启动方式见 [README.md](README.md)。

1. 初始是第 4 步，不默认展开计算器。
2. 点击 1K 的“估算成本”，再切换 2K / 4K。
3. 修改积分消耗；在宽屏左侧修改当前售价，差额即时更新。
4. Escape 或右上角关闭；已经查看的行保留成本摘要。
5. 点击五步导航，再返回单价，查看输入保留。
6. 点击右上角日光图标切换主题；缩窄到 390px 查看底部抽屉。
7. 返回模型列表可搜索、切换合成图片/视频商品；视频显示“按整条”。

所有账号、商品、金额和状态均为合成演示，不代表生产 Account #77 的当前情况。页面未连接业务 API；保存、发布、销售按钮只展示清楚标注的操作预览对话框，不执行或伪造成功。
